# 1541 checksum

A little programme to calculate and set the checksum(s) of a (set of) ROMs for the Commodore 1541 family of floppy disk drives.

Written in 6502 assembler. The current version only runs on a Commodore BASIC 4.0 computer with 32 kbyte of RAM, but adapting it for a BASIC 2.0 machine, a 64 or a 128 computer is easily done by changing some definitions.
