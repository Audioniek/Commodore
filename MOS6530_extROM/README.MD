# MOS 6530 external ROM
 
<img src="https://github.com/Audioniek/Commodore/blob/main/MOS6530_extROM/Pictures/MOS6530_ExtROM.png" width="300"/>

This is a very simple circuit that enables to use different a different ROM with an existing MOS 6530 RRIOT. The circuit can be used when upgrading the DOS ROMs of a Commodore 2040, 3040 or 8050 IEEE dual drive floppy.
